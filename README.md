# Netivo Action Logger (MU)

Standalone must-use WordPress plugin that streams admin user actions to Netivo
Action Logger telemetry. Unlike `packages/wp-module`, this package does not
depend on `netivo/wp-core` or a Netivo theme, and is meant to be dropped into
`wp-content/mu-plugins/` on any WordPress site.

Full installation and configuration instructions follow as the package is
built out.
